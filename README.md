# 🌦️ Weather Web App

A responsive **Weather App** built with **HTML, CSS, and JavaScript** that fetches real-time weather information using a weather API.

Users can search for any city or use their **current location** to quickly view essential weather details through a clean, responsive, and user-friendly interface.

## ✨ Features

* 🌍 **Search Any City** — Get weather information for cities around the world.
* 📍 **Current Location** — Use your device's location to fetch local weather.
* 🌡️ **Temperature** — View the current temperature of the selected location.
* ☁️ **Weather Conditions** — Displays the current weather condition.
* 💧 **Humidity** — Shows the current humidity level.
* 💨 **Wind Speed** — Displays the current wind speed.
* 📱 **Responsive Design** — Works across desktops, tablets, and mobile devices.
* ⚡ **Real-Time Data** — Weather information is fetched dynamically through a weather API.
* 🎨 **Clean Interface** — Simple and intuitive UI for a smooth user experience.

## 🛠️ Technologies Used

* **HTML5** — Structure and layout
* **CSS3** — Styling, responsiveness, and UI design
* **JavaScript** — API integration, location handling, and dynamic content
* **Weather API** — Fetching real-time weather data

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/eshanmaity/Weather-Web-App.git
```

### 2. Open the project

```bash
cd Weather-Web-App
```

### 3. Run the app

Open `index.html` in your browser.

## 🔑 API Setup

This project requires a weather API to retrieve real-time weather data.

If the API requires an API key:

1. Create an account with the weather API provider.
2. Generate your API key.
3. Add the key to the appropriate location in `script.js`.
4. Do **not** commit your API key to GitHub.

> ⚠️ Never expose private API keys in a public repository. Use environment variables or another secure method when required.
